# WhiteRP — стартовый gamemode для Garry's Mod

В репозитории создана самостоятельная основа RP-режима `whiterp` на базе Sandbox. Это не DarkRP и не замена всех сторонних аддонов: профессии, экономика, HUD/Q-menu, доска работ, базовые инструменты и серверные проверки реализованы в самом gamemode.

## Установка и запуск

1. Скопируйте `gamemodes/whiterp` в `garrysmod/gamemodes/` на сервере.
2. Запустите карту с параметром `+gamemode whiterp` (или выберите WhiteRP в меню новой игры).
3. Перезапустите карту после установки. Для проверки Lua смотрите серверную консоль на сообщения с префиксом `[WhiteRP]`.
4. Администратор открывает Q-меню клавишей Q. Админ-панель игроков открывается клавишей F3 или командой `wrp_adminpanel`.

## Что уже работает

- Профессии из `gamemode/shared.lua`: житель, строитель, полицейский, медик и механик. Сервер проверяет вместимость и задержку смены.
- Деньги сохраняются в PData игрока; сервер начисляет зарплату каждые пять минут. Баланс и работа передаются через NW2 vars.
- Администраторская панель: назначение работы, изменение баланса, bring/goto, freeze и kick. Сервер проверяет права, ограничивает частоту запросов и пишет действия в журнал.
- Админ ставит NPC-рекрутера профессий из вкладки «Сущности». Игрок подходит и нажимает E, после чего выбирает профессию.
- Новый HUD в тёмной полупрозрачной палитре с оранжевыми акцентами, состоянием игрока, деньгами, работой, временем до выплаты и боеприпасами. Он использует оригинальную отрисовку, без заимствованных Payday-файлов или материалов.
- Кастомный Q-menu: обычным игрокам доступны избранное и разрешённые инструменты; каталог пропов, NPC и WhiteRP-сущностей показывается администраторам. ПКМ по карточке пропа добавляет/убирает избранное.
- Инструменты WhiteRP: материал (встроенный Sandbox), скрывающаяся дверь, keypad с кодом 4–8 цифр, ограниченный толкатель пропов и удаление собственных объектов. Для двери владелец нажимает E рядом; закрытая дверь скрыта, но остаётся физическим препятствием. Доступ по коду выдаётся на восемь секунд.
- Начальная библиотека оружия `weapon_whiterp_base` и служебный пистолет: параметры урона/разброса/скорострельности, серверный hitscan с лаг-компенсацией, отдача, перезарядка и прицеливание. Пистолет выдаётся полиции; выдача/спавн оружия через Sandbox закрыты для не-администраторов.
- Базовые серверные ограничения: лимит и rate limit пропов, административный спавн NPC/машин/сущностей, проверка владельца при physgun/tool/property, whitelist инструментов и проверка каждой сетевой операции на сервере.

## Настройка

- Измените список работ, оплату, модели и лимиты в `gamemode/shared.lua`.
- Там же находятся `StartMoney`, `PaydayInterval`, `DefaultPropLimit`, `AdminPropLimit` и список инструментов.
- Основные серверные правила находятся в `gamemode/whiterp/sv_security.lua`; сетевые операции — в `sv_jobs.lua`, `sv_admin.lua`, `sv_tools.lua`.
- Администратор может задать деньги из консоли: `wrp_setmoney <SteamID> <сумма>`.

## Границы первой версии

Серверные ограничения снижают злоупотребления, но не являются античитом уровня VAC и не могут гарантированно обнаруживать внешние читы. Для публичного сервера дополнительно нужны актуальные серверные аддоны/античит, резервные копии, аудит, настройки сетевой инфраструктуры и тестирование на конкретной сборке. В первой версии нет полноценной базы бизнесов, системы законов/арестов, организаций, транспорта для гражданских, системы обвесов/баллистики/анимаций оружия и веб-интерфейса для наказаний и логов. Оружейная база — рабочий стартовый каркас, а не законченная большая библиотека контента; эти системы не следует считать готовыми только по наличию меню или заготовок.
